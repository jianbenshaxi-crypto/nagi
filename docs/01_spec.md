＃＃５．イレギュラーケース

１．空っぽ（何も入力せず押したら）：
［未入力 → 送信不可＋「今の気持ちを一言だけでも大丈夫です」］

２．過剰（想定の10倍を入れたら）：
［長い文章は、要点をまとめて記録します。］

３．悪意（変な文字列を入れたら）：
［意味のない文字列 → 記録・AI処理しない
不適切な入力 → エラー表示
深刻な悩み → 否定せず、安全を優先した案内］

４．中断（途中で閉じたら）：
［途中（そこまでの）の記録を残す
→ 次回「続きから」or「最初から」］
